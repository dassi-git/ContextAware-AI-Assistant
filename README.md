# 🤖 סוכן RAG חכם - פרויקט דסי

מערכת Retrieval-Augmented Generation (RAG) המאפשרת לצ'אטבוט מבוסס AI לענות על שאלות מתוך מסמכי פרויקט אישיים.

## 🌟 יכולות המערכת
- **אינדוקס מסמכים:** קריאת קבצי Markdown והפיכתם לבסיס נתונים וקטורי.
- **שליפה חכמה:** חיפוש במידע המקומי ומציאת הקטעים הרלוונטיים ביותר לשאלה.
- **מענה מבוסס הקשר:** שימוש ב-OpenAI (GPT-3.5) לניסוח תשובות מדויקות על בסיס המסמכים.
- **ממשק משתמש:** ממשק צ'אט גרפי נוח וידידותי.

## 🛠️ טכנולוגיות
- **Python 3.11**
- **LlamaIndex:** ניהול תהליך ה-RAG והאינדוקס.
- **OpenAI:** מודל שפה (LLM) ומודל Embeddings.
- **Gradio:** ממשק משתמש גרפי.
- **Local Storage:** אחסון וקטורי מקומי (עוקף חסימות רשת).

## 🚀 הוראות הפעלה

### 1. הגדרת מפתחות
יש ליצור קובץ `.env` ולהוסיף את המפתח שלך:
`OPENAI_API_KEY=your_key_here`

### 2. אינדוקס הנתונים
כדי לעבד את המסמכים בתיקיית `data_source` וליצור את הזיכרון המקומי, הרץ:
```bash
python ingest.py
